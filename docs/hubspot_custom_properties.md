# HubSpot Custom Properties Specification

The following custom properties must be configured under the **Contacts** object in HubSpot prior to executing the n8n pipeline.

These fields are populated directly via the `Create Contact in HubSpot` node.

| Property Label | Internal Name | Field Type | Object / Group | Description & Source |
| :--- | :--- | :--- | :--- | :--- |
| **Lead Score** | `lead_score` | Number | Contact Information | ICP fit score (range: 0–100) generated by OpenAI BANT evaluation |
| **BANT Budget** | `bant_budget` | Multi-line text | Contact Information | Synthesized assessment of financial capacity, pricing model, and revenue indicators |
| **BANT Authority** | `bant_authority` | Multi-line text | Contact Information | Evaluation of decision-maker accessibility and corporate hierarchy indicators |
| **BANT Need** | `bant_need` | Multi-line text | Contact Information | Identification of operational friction, manual workflows, and automation opportunities |
| **BANT Timing** | `bant_timing` | Multi-line text | Contact Information | Assessment of company momentum, service expansion, and hiring triggers |
| **Company Size** | `company_size` | Single-line text | Company / Contact Info | Estimated organizational footprint (`small`, `medium`, `large`) |

---

### Implementation & Architecture Notes:
1. **Gated CRM Synchronization:** Records are committed to HubSpot exclusively for qualified candidates passing the threshold filter (`lead_score >= 70`).
2. **PII Protection & Deduplication:** Contacts are provisioned using a deterministic placeholder routing format (`lead-YYYY-MM-DD-[hash]@placeholder.com`). Validated tax identification numbers (`NIP`) are extracted and preserved upstream to serve as unique business keys for enrichment via official registers (CEIDG/KRS).
